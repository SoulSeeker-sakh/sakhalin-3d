Интерактивная 3D-карта нефтегазовой инфраструктуры острова Сахалин и Дальнего Востока, подготовленная в рамках проекта **Сахалинского государственного университета (СахГУ)**.

## Открыть онлайн
- **[Запустить интерактивную 3D-карту →](https://soulseeker-sakh.github.io/sakhalin-3d/)**
- **[Смотреть 3D-синематик (1:30) →](https://soulseeker-sakh.github.io/sakhalin-3d/cinematic.html)**

> На телефоне (Android / iPhone) или ПК карту можно установить как отдельное приложение (**«На экран Домой / Установить»**) — после первого открытия она работает и без интернета.

## Проекты на карте

| Проект | Оператор | Ключевые объекты |
|---|---|---|
| **«Сахалин-2»** | ООО «Сахалинская Энергия» | Платформы ПА-А «Моликпак», ПА-Б, ЛУН-А, ОБТК, НКС-2, ПК «Пригородное» (завод СПГ и ТОН), вертолёт и флот |
| **«Сахалин-1»** | ПАО «НК «Роснефть» / ООО «Сахалин-1» | Одопту, «Орлан», «Беркут», БКП «Чайво» + БУ «Ястреб», терминал «Де-Кастри» и ледовая проводка танкеров |
| **«Сахалин-3»** | ПАО «Газпром» *(Газпром добыча шельф)* | Подводный добычной комплекс (ПДК) Киринского и Южно-Киринского месторождений с подводным режимом X-Ray |
| **МГП СХВ** | ПАО «Газпром» *(Газпром трансгаз Томск)* | Магистральный газопровод «Сахалин — Хабаровск — Владивосток» до Хабаровска, Владивостока и о. Русский |

## Возможности
- **Стартовая 3D-планета** с гербом **СахГУ** и плавным погружением сквозь облака на остров Сахалин.
- **Смена погоды и атмосферы:** «Лето • День» → «Снег • День» → «Снег • Ночь» со снегопадом, дрейфующими льдами и ночными огнями городов.
- **Подводный режим (X-Ray)** для осмотра морских трубопроводов и подводного добычного комплекса на дне Охотского моря.
- **Автоматический 3D-синематик** (`cinematic.html`): 90-секундный кинопролёт с перемоткой, музыкой и сохранением видео.
- **Двуязычный интерфейс:** Русский / English.

## Структура репозитория
```text
sakhalin-3d/
├── index.html          # Главная интерактивная 3D-карта
├── cinematic.html      # Автоматический 90-секундный 3D-синематик
├── manifest.json       # Манифест PWA для установки на телефон и ПК
├── sw.js               # Service Worker для офлайн-работы
├── icons/              # Иконки приложения (192×192, 512×512)
├── docs/               # Схема геоданных и справочников (data_schema.md)
└── src/                # Исходный код, разбитый по модулям
    ├── core/           # Базовое состояние и проекция координат
    ├── data/           # Береговые линии, объекты и логотипы операторов
    ├── terrain/        # Океан, рельеф острова и гео-утилиты
    ├── sakhalin1/      # «Сахалин-1», «Сахалин-3», МГП СХВ, льды, облака
    ├── sakhalin2/      # «Сахалин-2»: платформы, завод СПГ, трубопроводы
    ├── intro/          # Стартовая 3D-планета и герб СахГУ
    ├── engine/         # Главный цикл рендеринга и инициализация
    ├── ui/             # Карточки объектов, модальные окна, управление
    ├── i18n/           # Перевод интерфейса (RU / EN)
    ├── audio/          # Процедурный звук и киномузыка (Web Audio API)
    ├── polish/         # Снегопад, следы судов, адаптация под устройства
    ├── cinematic/      # Режиссёр 3D-синематика и запись видео
    └── styles/         # Стили интерфейса
```
